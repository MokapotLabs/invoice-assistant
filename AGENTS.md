# Project instructions

Use a small typed TPF pipeline. Verify framework capabilities against the pinned 26.10.1-SNAPSHOT compiler and version-matching source; use tpf-authoring for application changes. `await:` is an operation modifier, not a StepKind.

Preserve existing dirty files. Keep authored changes isolated on a feature branch. Use Optional/empty collections for optional application state and validate record invariants. Run focused tests then relevant module tests. Mail verification uses fixtures unless the user explicitly authorizes a test mailbox. Never send customer PDFs or credentials to review services. Format touched files and inspect the final diff for private data.
